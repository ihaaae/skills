| `progit.epub` | Pro Git 第二版中文版（Scott Chacon、Ben Straub 著，社区翻译） | <https://github.com/progit/progit2-zh/releases> | [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/) |
