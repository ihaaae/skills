### N1  IP 只负责尽力把 packet 送到对方机器
**主张**：IP 是 best effort：路由器按目的地址转发 packet，不保证送到、不保证顺序、不去重，也不通知发送方。可靠性要靠更上层（如 TCP）自己做。
**例子**：发 3 个 packet，对方可能收到 1、3、2，也可能只收到 1、3。

### N2  port
**主张**：IP 地址找到机器，port 找到机器上的程序。浏览器连 `example.com:443`，就是连那台机器上监听 443 的程序。一条 TCP 连接由（本地 IP、本地 port、对方 IP、对方 port）四个值确定。
