# 解读「巴特兹」（猩皇威武）的篮球评论

作者 ID 为巴特兹，文章署名「猩皇威武」，发于微信公众号（有"阅读数/投诉/编辑记录"界面特征）。文章有两大障碍：通篇谐音暗语，以及跨联赛、跨项目的类比论证。解读任何一段选文，按下面的四步流程走。

## 四步解码流程

1. **解暗语**：先查 `references/glossary.md` 的暗语词典。词典里没有的，用三条推断规则：
   - **谐音生僻字**：把生僻字读出来即得本字（偌置=弱智、敷溴=腐朽、砂嘶=杀死、泽任=责任、痧/煞=傻→姚明）。作者用生僻字规避审核并叠加贬义。
   - **单字/排行代号**：取姓氏或名字的一个字（森=杨瀚森、虚=崔永熙、勃=曾凡博、麟=张镇麟），或体型/诨名（226=姚明身高、大叔=穆托姆博、二叔=朱万·霍华德）。
   - **英语谐音**：Handsome Young=杨瀚森（Young≈杨，Handsome≈瀚森）、桑嗨=上海、本李=李弘权（Ben Li）、love=瓦格纳·勒夫（Vágner Love）。
   推断出的新对应关系要标注"（推断）"，并向用户说明依据；解完可以顺手补进词典。
2. **还原事件**：把人名、球队、赛事代换回真实实体，确定文章讨论的具体比赛/赛季/窗口期（词典里有已确认的事件锚点，如"亚洲杯亚军"=2025男篮亚洲杯）。
3. **拆论证**：识别作者使用的论证模板，见 `references/argumentation.md`。最关键的是**引号角色槽位**：带引号的人名（如"李祥波""胡金秋"出现在2007火箭语境）不是实力对比，而是把另一套语境里的角色映射过来。先找映射表，再理解论点。
4. **核验数据**：作者列的 on/off、百回合、阵容分钟拆分等数字通常是真实且内部自洽的，但结论常靠辩论术放大。按 `references/factcheck.md` 的流程核验，重点检查其中列出的"已知手法弱点"。该文件还记录了已核验过的系列赛（2004/2005/2007/2008/2009），不要重复劳动，直接引用结论。

## 作者的核心母题（所有文章共享）

- **造猩批判**：篮协（"姚朱熹"）硬捧旅外/造星，损害国家队队友情绪与体系；姚明是"造猩"的原型与源头。
- **权责对等**：金元联赛/高薪虚高者不该占据国家队位置；"有功赏，有错罚"。
- **让想打的人多打**：教练能控制的只有用人；为饭碗拼命的角色球员 > 有保障合同的球星。
- **体系>球星**：正确的角色结构（苦力+技术内线、真掩护、球路制造者）能让弱球员存活、让核心休息；反之球星是"乘客不是司机"。

## 输出风格

解读时用中文回答。区分三类内容并明确标注：**暗语解码**（词典/推断）、**作者观点**（他的主张是什么）、**核验结论**（数据是否支持，以及支持到什么程度）。作者的数据功底真实，不要全盘否定；他的问题是选择性细分（对喜欢的球员做逐回合细分、对姚明拒绝同样的慈善），指出这一点比争论单个数字更有力。
